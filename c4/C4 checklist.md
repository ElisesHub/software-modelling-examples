# Software architecture diagram review checklist

Adapted from the [Software architecture diagram review checklist](https://c4model.com/diagrams/checklist)
by Simon Brown, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Kept here for my own personal reference.

## General

| Question                                           | Yes | No  |
| -------------------------------------------------- | --- | --- |
| Is there a title on the diagram?                   |     |     |
| Is it clear what kind of diagram this is?          |     |     |
| Is it clear what the diagram covers (its scope)?   |     |     |
| Is there a key or legend?                          |     |     |

## Elements

| Question                                                                                       | Yes | No  |
| ---------------------------------------------------------------------------------------------- | --- | --- |
| Is every element named?                                                                        |     |     |
| Is each element's type clear (its level of abstraction, e.g. software system, container)?      |     |     |
| Is each element's responsibility clear?                                                        |     |     |
| Where relevant, is each element's technology shown and clear?                                  |     |     |
| Are all acronyms and abbreviations explained or obvious?                                       |     |     |
| Is the meaning of every colour clear?                                                          |     |     |
| Is the meaning of every shape clear?                                                           |     |     |
| Is the meaning of every icon clear?                                                            |     |     |
| Is the meaning of every border style (solid, dashed, etc.) clear?                              |     |     |
| Is the meaning of different element sizes clear (e.g. small vs large boxes)?                   |     |     |

## Relationships

| Question                                                                                       | Yes | No  |
| ---------------------------------------------------------------------------------------------- | --- | --- |
| Is every arrow labelled with the intent of the relationship?                                   |     |     |
| Does each label read correctly in the direction of its arrow?                                  |     |     |
| Where relevant, is the technology of each relationship clear (e.g. the protocol)?              |     |     |
| Are all acronyms and abbreviations explained or obvious?                                       |     |     |
| Is the meaning of every colour clear?                                                          |     |     |
| Is the meaning of every arrowhead clear?                                                       |     |     |
| Is the meaning of every line style (solid, dashed, etc.) clear?                                |     |     |

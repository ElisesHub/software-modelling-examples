# Software Modelling Examples

A personal reference collection of software modelling examples, kept so I can
refer back to them when modelling a new system.

All examples describe the same fictional online banking system, so the different
models can be compared side by side. It is not a real system.


## Contents

- **C4 model**: all four levels (System Context, Container, Component, Code)

To come: 
- **Entity-Relationship diagram**: the database behind the example system
- **Sequence diagram**: one scenario showing how the parts interact at runtime

## Viewing and editing

Diagrams are saved as `.drawio.svg` files. They display as normal images on GitHub and in Obsidian, and open as fully editable diagrams in [draw.io](https://www.drawio.com).
